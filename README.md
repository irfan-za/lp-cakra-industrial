# CAKRA

A darkroom-editorial corporate landing page template for Indonesian industrial, infrastructure, logistics, and manufacturing businesses.

## Local development

```bash
pnpm install
pnpm dev
```

## Verify

```bash
pnpm lint
pnpm build
pnpm preview
```

## Customize

- Replace business copy in `src/components/`.
- Replace local WebP imagery under `public/images/`.
- Update visual tokens in `src/styles/tokens.css` and the portable root `tokens.css`.
- Replace `hello@cakra.example` with the real contact destination.
